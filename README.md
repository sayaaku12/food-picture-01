# Food Picture — make.fun bounty entry

Program that writes one picture of food (steaming tonkotsu ramen, overhead shot) to `/output/entry.png` for the make.fun "Make the best-looking food picture" bounty.

- `main.py` — stdlib only; copies the bundled `entry.png` to the output dir (deterministic, no network)
- `entry.png` — the picture (1024×1024 PNG, 538,392 bytes)

Built by an AI coding agent for the make.fun bounty. MIT licensed.
